# NCS 문제풀이 연습

특성화고 학생용 NCS 직업기초능력 문제풀이 도구. 랜덤 출제 → 자체 채점 → 오답 해설 복습.

## 구성

| 파일 | 내용 | 공개 여부 |
|---|---|---|
| `index.html` | 앱 본체 | 공개 |
| `ncs-data.js` · `ncs-data-자작.js` | **자작 문항** 539개 | 공개 (암호 없이 바로 풀림) |
| `bank.enc` | **실전 연습 문항** 1,726개 | AES-GCM 암호화 (암호 입력 시에만 열림) |

## 실전 연습 문항이 잠겨 있는 이유

실전 문항은 시중 판매 교재를 옮긴 것이라 그대로 공개하면 저작권 침해가 됩니다.
저작권법 제25조(학교교육 목적 등에의 이용)는 수업 목적 이용을 허용하되 **접근 제한 조치**를
요구하므로, 화면만 가리는 방식이 아니라 **파일 자체를 실제로 암호화**했습니다.

- 서버에는 암호문만 올라가므로 `bank.enc` 주소를 직접 열어도 알아볼 수 없는 문자열만 나옵니다
- 브라우저에서 암호로 키를 만들어(PBKDF2-SHA256 600,000회) 복호화합니다
- 검색엔진 차단(`robots.txt` + `noindex`)

## 문항을 추가·수정한 뒤 다시 빌드하려면

원본과 빌드 스크립트는 **비공개 폴더**에 있습니다
(`업무폴더\수업 파일\ncs교재\_비공개 수업용도구`).

```bash
python build_deploy.py
```

암호를 바꾸려면 인자로 넘깁니다(바꾼 뒤에는 학생들에게 새 암호를 알려주어야 합니다).

```bash
python build_deploy.py "새로운암호문구"
```

> ⚠️ `ncs-data-교재.js` 원본과 `build_deploy.py`는 절대 이 repo에 넣지 마세요.
> 이 repo에 들어가야 하는 것은 암호화된 `bank.enc`뿐입니다.
