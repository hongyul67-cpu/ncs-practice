# NCS 문제풀이 연습

특성화고 학생용 NCS 직업기초능력 문제풀이 도구. 랜덤 출제 → 자체 채점 → 오답 해설 복습.

## 구성

| 파일 | 내용 | 공개 여부 |
|---|---|---|
| `index.html` | 앱 본체 | 공개 |
| `ncs-data.js` · `ncs-data-자작.js` | **자작 문항** 539개 | 공개 (암호 없이 바로 풀림) |
| `bank.enc` | **실전 연습 문항** 1,726개 | AES-GCM 암호화 (암호 입력 시에만 열림) |

## 암호 두 종류

| 종류 | 형태 | 유효기간 |
|---|---|---|
| 교사용 | 문구형 (`ncs-siljeon-2281`) | 없음 |
| 학생용 | **8자리 숫자** (`1234 5678`) | 그 주 월요일 ~ 다음 월요일 **7일** |

**교사용으로 열면 학생 코드가 화면에 바로 나옵니다.** 이번 주 코드가 크게 뜨고,
이후 12주 목록과 날짜로 찾기, 전체 260주 보기가 있습니다. 코드표 파일을 뒤질 필요가 없습니다.

학생 코드는 날짜에서 계산됩니다.

```
코드 = HMAC-SHA256(마스터 시크릿, "NCSW|" + 그 주 월요일 YYYY-MM-DD) 앞 4바이트 → 8자리
```

마스터 시크릿은 **교사용 암호로 감싼 안쪽에만** 들어 있어, 학생 코드로 열면 다른 주 코드를
계산할 수 없습니다. 빌드 한 번으로 **260주(5년)** 치가 깔리므로 3년이 지나도 그대로 씁니다.

유효기간은 암호문 **안에** 들어 있어 화면이나 코드를 고쳐도 통하지 않습니다.
시작일 전(`아직 쓸 수 없는 코드입니다`)과 만료 후(`사용 기간이 끝난 코드입니다`) 모두 막히므로,
교사 화면을 본 학생이 다음 주 코드를 미리 쓸 수도 없습니다.

> 서버가 없으므로 "한 번 쓰면 죽는" 진짜 1회용은 만들 수 없습니다(사용 횟수를 세어 둘 곳이 없음).
> 또한 기간이 끝나도 **이미 연 기기는 계속 열립니다** — 만료는 *새로 여는 것*을 막습니다.
> 기기 시계를 조작하면 우회됩니다.

## 학습 기록 (오답 · 별표)

푼 결과가 브라우저에 저장되어 출제 방식을 고를 수 있습니다.

- 🎲 랜덤 출제 · ❌ 틀린 문항 · ⭐ 별표 문항 · 🆕 안 푼 문항
- 문제를 풀거나 오답 복습을 하면서 **☆ 담기**를 누르면 별표 문항으로 모입니다
- 기록은 그 기기에만 남습니다(서버 전송 없음). "기록 지우기"로 초기화

## 실전 연습 문항이 잠겨 있는 이유

실전 문항은 시중 판매 교재를 옮긴 것이라 그대로 공개하면 저작권 침해가 됩니다.
저작권법 제25조(학교교육 목적 등에의 이용)는 수업 목적 이용을 허용하되 **접근 제한 조치**를
요구하므로, 화면만 가리는 방식이 아니라 **파일 자체를 실제로 암호화**했습니다.

- 서버에는 암호문만 올라가므로 `bank.enc` 주소를 직접 열어도 알아볼 수 없는 문자열만 나옵니다
- 브라우저에서 암호로 키를 만들어(PBKDF2-SHA256 600,000회) 복호화합니다
- 검색엔진 차단(`robots.txt` + `noindex`)

## 문항을 추가·수정한 뒤 다시 빌드하려면

원본과 빌드 스크립트는 **비공개 폴더**에 있습니다
(`업무폴더\수업 파일\ncs교재\_비공개 수업용도구`).

```bash
python build_deploy.py
```

옵션은 `--pw`(교사용 암호) `--weeks`(주차 수, 기본 260) `--start`(1주차 시작 월요일, 기본 이번 주).

> ⚠️ **다시 빌드하면 마스터 시크릿이 새로 생겨 기존 학생 코드가 전부 무효**가 됩니다.
> 문항만 고쳤을 때도 마찬가지이니, 학기 중이라면 재빌드 후 학생들에게 새 코드를 알려주세요.

코드표 백업은 비공개 폴더의 `codes.txt`에 저장됩니다(평소엔 앱에서 보면 되므로 열 일이 없습니다).

> ⚠️ `ncs-data-교재.js` 원본, `build_deploy.py`, `codes.txt`는 절대 이 repo에 넣지 마세요.
> 이 repo에 들어가야 하는 것은 암호화된 `bank.enc`뿐입니다.
